# منصة القرآن واللغة العربية

منصة تعليمية موجهة لأبناء المغتربين، تعمل على GitHub Pages دون خادم ولا حساب، وبست لغات: العربية والإنجليزية والفرنسية والإسبانية والألمانية والإيطالية.

## الأقسام
- **`quran.html` حفظ القرآن:** ستة قرّاء، كاراوكي على مستوى الكلمة، إخفاء الكلمات والآيات، تسجيل المتعلم والاستماع إليه، نسبة التقدم.
- **`arabic.html` العربية والحديث والأخلاق:** مسار دروس بأسلوب الألعاب في ثماني وحدات، مع مكتبة أحاديث.

## البنية
```text
assets/css/style.css      التصميم
assets/fonts/             الخطوط (Baloo Bhaijaan 2 وAmiri Quran)
assets/js/i18n.js         اللغة الموحدة لكل الصفحات
assets/js/store.js        حفظ التقدم على الجهاز
assets/js/quran.js        قسم القرآن
assets/js/arabic.js       قسم العربية
data/translations.json    نصوص الواجهة باللغات الست
data/lessons.json         الوحدات والمفردات والجمل والأحاديث
data/quran/               نص المصحف
```

## التعديل على المحتوى
- لإضافة وحدة: أضف عنصرًا إلى `units` في `data/lessons.json` بست مفردات وثلاث جمل وحديث، وبكل اللغات.
- لإضافة نص في الواجهة: أضف مفتاحه في `data/translations.json` باللغات الست ثم استعمل `data-i18n`.

## المصادر
- نص المصحف بالرسم العثماني: حزمة [quran-json](https://github.com/risan/quran-json) عن موسوعة القرآن الكريم QuranEnc، برخصة CC BY 4.0، وقد قورن هيكله الحرفي آيةً آية بنص مشروع Tanzil.
- التلاوات وتوقيتات الكلمات: واجهة Quran.com (`api.quran.com`).
- ترجمات معاني القرآن: واجهة AlQuran.cloud (`api.alquran.cloud`).
- الخطوط: برخصة SIL Open Font License.

## الخصوصية
التقدم محفوظ في `localStorage`، والتسجيلات في `IndexedDB` على جهاز المستخدم، ولا يُرسل شيء منها إلى أي خادم.
